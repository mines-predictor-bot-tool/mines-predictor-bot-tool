## Mines Game and Predictor Information

Mines-style games usually display a board containing hidden mines and safe cells.

The player selects cells without knowing where the mines are located. The exact rules, board size, number of mines and result generation can vary between platforms.

A Mines Predictor may provide suggestions or analytical information, but it cannot guarantee the location of hidden mines in a randomly generated board.

Users should treat all predictor and signal information as optional project content rather than certain knowledge of a future result.
